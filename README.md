# Daily AI News Automation

An automated AI news digest built using n8n, Google News RSS, Google Gemini, and Gmail.

## Project Overview

Daily AI News Automation is a workflow automation project that collects AI-related news, uses a large language model (LLM) to select and summarize important stories, generates an HTML news digest, and sends it by email.

The project demonstrates how workflow automation and generative AI can be combined to reduce manual effort in gathering and reading technology news.

## Key Features

- **Scheduled Automation:** Runs daily using an n8n Schedule Trigger.
- **News Collection:** Retrieves AI-related news through Google News RSS.
- **Content Processing:** Limits the collected news items and aggregates them for analysis.
- **AI-Powered Summarization:** Uses Google Gemini to select and summarize the top five stories.
- **HTML News Digest:** Generates a structured digest with headlines, summaries, takeaways, and source links.
- **Email Delivery:** Sends the generated digest through Gmail.

## Technologies Used

- n8n — Workflow automation
- Google News RSS — News collection
- Google Gemini — AI-powered content analysis and summarization
- Gmail — Email delivery
- JSON — Workflow configuration
- HTML — News digest formatting

## Workflow Architecture

Schedule Trigger → Google News RSS → Limit → Aggregate → Google Gemini LLM Chain → Gmail

## How It Works

1. The schedule trigger starts the workflow at the configured time.
2. The RSS node retrieves news matching AI-related search terms.
3. The Limit node restricts the number of news items to ten.
4. The Aggregate node combines the items for the LLM chain.
5. Google Gemini analyzes the collected items and generates a top-five AI news digest.
6. The Gmail node sends the generated digest to the configured email address.

## Setup Instructions

1. Install or access an n8n instance.
2. Import `daily-ai-news-automation.json`.
3. Configure your own Google Gemini and Gmail credentials.
4. Review the schedule and timezone settings.
5. Test the workflow manually and verify the generated email.
6. Activate the workflow after successful testing.

Note: External service access, credentials, and an appropriate n8n environment are required. The exported workflow does not include working credentials.
